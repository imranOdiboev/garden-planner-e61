# Планировщик садового участка 2025_Е61

Учебное приложение для планирования застройки садового участка или территории частного дома. Оно предоставляет 2D редактор, измерение расстояний и проверку размещения по структурированным правилам. Сервер реализован на Python и FastAPI. Интерфейс использует HTML, CSS, JavaScript и SVG. Планы и база правил хранятся в JSON.

## 1 Реализованные функции

- Задание размеров и редактирование вершин собственного и соседних участков. Отображение сетки, масштаба и границ.
- Добавление, выбор, перемещение, поворот, изменение размеров и удаление объектов. Каталог включает дом, гараж, баню, хозяйственную постройку, септик, выгребную яму, колодец, грядку, теплицу, куст и дерево.
- Редактирование ломаных электричества, газа, канализации и водоснабжения.
- Измерение между точками, контурами объектов и границами участков. Расчёты учитывают размеры и поворот.
- Проверка пересечений, выхода за границы и условий правил. Результаты имеют статусы «нарушение», «соответствует» и «недостаточно данных».
- Сохранение и загрузка JSON. Просмотр, редактирование, подтверждение и импорт базы правил.
- Подключение к локальной языковой модели Ollama. Получение кандидатов правил и проверка их структуры. Включение кандидатов после просмотра пользователем.
- Набор размеченных текстов и сценарий оценки двух порядков анализа.

**Шесть демонстрационных правил и десять текстов для оценки синтетические. Числовые значения не являются действующими СНиП или СП.** Проверенная нормативная база отсутствует. Нейросетевой эксперимент не выполнен; качество извлечения не измерено.

## 2 Требования к системе

- Windows и Python 3.12 с Python Launcher.
- Браузер с поддержкой JavaScript и SVG.
- Папка проекта с разрешением на запись.
- Доступ к интернету для установки зависимостей и загрузки весов модели.
- Ollama и установленная языковая модель для анализа текста. Остальные функции работают без модели.

Расход памяти и время нейросетевой обработки зависят от модели и оборудования. Минимальные аппаратные требования для этого модуля не измерены.

## 3 Установка и запуск

Скачайте репозиторий [imranOdiboev/garden-planner-e61](https://github.com/imranOdiboev/garden-planner-e61) через **Code → Download ZIP** и распакуйте архив. Откройте PowerShell в папке, содержащей `README.md` и `requirements.txt`.

При установленном Git можно выполнить:

```powershell
git clone https://github.com/imranOdiboev/garden-planner-e61.git
cd garden-planner-e61
```

Установите [Python 3.12](https://www.python.org/downloads/windows/) и выполните из корня проекта:

```powershell
py -3.12 --version
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте <http://127.0.0.1:8000>. Окно сервера должно оставаться открытым. Для остановки нажмите `Ctrl+C`.

После установки повторный запуск выполняется командой:

```powershell
.\run.bat
```

Если Python Launcher отсутствует, используйте `python` вместо `py -3.12`, предварительно проверив версию через `python --version`. Если порт 8000 занят, остановите другой сервер или укажите `--port 8001` и откройте `http://127.0.0.1:8001`. Все версии зависимостей среды проверки сохранены в `requirements-lock.txt`.

## 4 Краткая инструкция пользователя

1. Нажмите **«Открыть пример»**. План содержит собственный участок 30 × 40 м, два соседних участка, 12 объектов и четыре коммуникации.
2. Задайте размеры слева или включите **«Границы»** для изменения вершин. Координаты и количество вершин редактируются справа.
3. Выберите участок и тип объекта в каталоге. Щёлкните на плане для добавления. Перемещайте объект мышью. Название, размеры, угол и характеристики изменяются в свойствах; затем нажмите **«Применить изменения»**.
4. Для коммуникации задайте точки и нажмите **«Завершить линию»**. У выбранной линии можно перемещать точки и менять их координаты.
5. Инструмент **«Измерить»** задаёт две точки. Списки «От» и «До» справа используются для измерения между контурами и границами.
6. Нажмите **«Проверить план»**. Результаты содержат объекты, фактическое и требуемое расстояние, условия, объяснение и источник. Команда **«Показать на плане»** выделяет объект.
7. Используйте **«Скачать план»** и **«Загрузить JSON»** для обмена планами. База правил скачивается и импортируется отдельно на вкладке **«База правил»**. Импорт заменяет текущую базу.

`Ctrl+Z` и `Ctrl+Y` отменяют и повторяют изменения плана. Колесо меняет масштаб. `Shift` с перетаскиванием сдвигает вид. Кнопка **«Весь план»** показывает видимые участки. `Esc` отменяет незавершённую линию.

## 5 Настройка нейросетевого модуля

Установите [Ollama для Windows](https://ollama.com/download/windows). Загрузите модель по умолчанию:

```powershell
ollama pull qwen2.5:3b
ollama list
```

Если сервис Ollama не запущен, выполните в отдельном окне:

```powershell
ollama serve
```

На вкладке **«Анализ текста»** укажите установленную модель и нажмите **«Проверить модель»**. Вставьте текст или загрузите TXT в UTF-8. Укажите источник и запустите извлечение. Кандидаты доступны для просмотра и исправления. Активная база изменяется только после подтверждения пользователем.

При недоступности Ollama или выбранной модели анализ возвращает сообщение об ошибке и не создаёт кандидаты. Редактор остаётся доступным. Настройки подключения, параметры модели, этапы и сценарий оценки описаны в [NEURAL_METHOD.md](docs/NEURAL_METHOD.md).

## 6 Запуск тестов

Из корня проекта выполните:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

Дополнительные пакеты и запущенная модель не требуются. Последняя документированная проверка: **54 теста пройдены**. Вывод запуска, HTTP-сценарии и результаты учебного примера приведены в [VERIFICATION.md](docs/VERIFICATION.md).

## 7 Известные ограничения

- Проверенная нормативная база не включена. Демонстрационные правила применяются только для проверки учебного прототипа.
- Извлечение установленной языковой моделью и сравнение порядков этапов ещё не проверены экспериментально.
- Контуры объектов прямоугольные. Для растений это условная проекция кроны.
- Коммуникации редактируются и сохраняются, но их нормативные ограничения не проверяются.
- Поддерживается ограниченный набор параметров и условий. Сложные условия и приоритет источников требуют ручной проверки.
- Приложение предназначено для локальной работы одного пользователя. Совместное редактирование не реализовано.

Работы, необходимые для завершения задания Е61, перечислены в [разделе отчёта](docs/REPORT_DRAFT.md#8-работы-для-завершения-задания-е61).

|---|---|
| `app/` | Сервер, геометрия, проверка правил и модуль Ollama |

| `data/` | Пример плана, демонстрационная и текущая базы правил |

| `requirements.txt`, `requirements-lock.txt` | Зависимости и зафиксированные версии |
| `run.bat` | Запуск сервера после установки |
