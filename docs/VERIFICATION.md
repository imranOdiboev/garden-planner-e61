# Фактическая проверка проекта

Состояние на 14 октября 2026 года. Проверки выполнены в рабочей папке `D:\идз` на Windows со встроенным Python 3.12.14; окружение проекта `.venv`. Версии сохранены в `requirements-lock.txt`.

## Автоматические проверки

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

**54 теста пройдены, ошибок и пропусков нет.** Тесты используют стандартный `unittest`; дополнительных пакетов для тестирования не требуется.

| Модуль тестов | Проверяется |
|---|---|
| `test_core.py` | Кратчайшие расстояния, поворот, касание, вложение, вогнутые границы, формат JSON, условия/исключения, единицы и отношения правил |
| `test_api_logic.py` | Подтверждение/запись базы, обновление ID, блокировка конфликтов/дублей, выключенные правила, импорт и измерительные конечные точки |
| `test_neural.py` | Формат реального HTTP-запроса, JSON Schema, неверная структура, обрезание, цитаты, разные порядки, запрет автоматической активации и недоступная модель |
| `test_evaluation.py` | TP/FP/FN и F1, пустые эталоны, перевод единиц с контекстом и штраф за ложный конфликт |

Примеры аналитических проверок: для прямоугольника 4 × 2 м в центре (0,0) и прямоугольника 2 × 2 м в (10,0) расстояние 7 м; при повороте первого на 90° — 8 м. Для квадрата 2 × 2 м под 45° и такого же квадрата в (5,0) расстояние `4 − √2` м. В вогнутом многоугольнике проверен случай, когда вершины объекта внутри, но ребро проходит через выемку.

## Реальный HTTP-сервер

Сервер запущен через Uvicorn на `127.0.0.1:8000`. Команда проверки:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\smoke_api.py
```

Проверены 8 сценариев: работоспособность; чтение/валидация JSON с полным сохранением; отклонение отрицательного размера; отклонение запроса от другой страницы; дистанция дом–граница 7 м; три статуса проверки; доступность Ollama; понятный HTTP 503 при отсутствии модели. Последний запуск после исправлений сервера прошёл. Машиночитаемый результат — `api-verification.json`.

Для исходного плана и шести включённых синтетических правил: **2 нарушения, 15 соответствий, 2 результата «недостаточно данных»**. Это детерминированные результаты учебного примера, не подтверждение строительных норм.

## Нейросетевой эксперимент

Проверен вызов сценария:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m evaluation.evaluate --model qwen2.5:3b --repeats 1 --seed 42 --temperature 0 --num-ctx 16384 --num-predict 4096
```

Ollama/модель недоступны. `evaluation/results/status.json` содержит **not_run**, причину, модель/параметры, протокол и `metrics: null`. Реальных ответов модели, F1 или утверждений о лучшем порядке нет. Заглушки транспорта применяются только в тестах; их нельзя выдавать за исследовательские результаты.

Для завершения экспериментальной части установите Ollama, загрузите модель и повторите CLI. При появлении реальных результатов проверьте ответы, покрытие и ошибки, затем обновите раздел экспериментов отчёта.
