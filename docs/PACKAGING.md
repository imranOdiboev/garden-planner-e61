# Упаковка исходников

Сервер и веса модели не надо отправлять вместе с проектом. Получатель устанавливает Python-зависимости и при необходимости Ollama отдельно.

1. Скачайте нужные планы и базу через интерфейс. Проверьте, что `data/rules.json` содержит именно ту учебную/подтверждённую базу, которую хотите передать.
2. В PowerShell из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\package_project.py
```

3. Откройте `dist/garden-planner-e61.zip` и убедитесь, что есть `README.md`, `requirements.txt`, папки `app`, `static`, `data`, `evaluation`, `tests`, `scripts`, `docs` и `run.bat`.
4. В архиве не должно быть `.venv`, `.git`, `.env`, `__pycache__`, файлов с паролями/ключами и весов модели. Генератор использует разрешённые папки и расширения, исключает служебные каталоги и типовые имена секретов. Перед передачей всё равно просмотрите собственные дополнения к исходникам: секрет может находиться внутри обычного файла с произвольным именем.
5. `MANIFEST.sha256` содержит контрольные суммы файлов. Для проверки архива на другой машине достаточно распаковать его и выполнить команды установки из README. Окружение создаётся заново; копировать `.venv` нельзя.

По умолчанию не включаются исходное `задание.docx`, сырые ответы нейросетевых запусков и произвольные пользовательские файлы вне разрешённых папок. Из `evaluation/results` включаются только текущий `status.json` и `comparison.md`, если он существует. Если преподавателю нужны полные результаты выполненного эксперимента, просмотрите эти JSON и добавьте их вручную отдельной папкой, проверив, что текст не содержит личных данных.

`scripts/prepare_data.py` заново создаёт синтетические данные и **перезаписывает `data/rules.json`**. Для обычного запуска это не требуется. Если хотите вернуть учебную базу, сначала скачайте текущую; затем импортируйте `data/demo_rules.json` через интерфейс или осознанно используйте генератор.

После распаковки в новую папку проведите тесты и откройте приложение. Ничего не публикуется и не отправляется автоматически.
