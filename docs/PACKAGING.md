# Упаковка исходников

## Сборка архива

Команда выполняется из корня проекта после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\package_project.py
```

Результат — `dist/garden-planner-e61.zip`. Файл `MANIFEST.sha256` содержит контрольные суммы включённых файлов.

## Состав

В архив включаются исходники, интерфейс, зависимости, примеры, тесты и документация. Используются папки `app`, `static`, `data`, `tests`, `scripts`, `evaluation`, `docs`. Также включаются `README.md`, `requirements.txt`, `requirements-lock.txt`, `run.bat` и `.gitignore`.

Не включаются виртуальное окружение, служебные каталоги, `.env`, типовые файлы секретов и двоичные веса модели. Из `evaluation/results` включаются только `status.json` и `comparison.md`, если они существуют. Исходный документ задания и файлы вне разрешённых папок не включаются.

Упаковщик фильтрует имена и расширения. Содержимое обычных файлов на наличие секретов не анализируется. Перед передачей проверяются файлы с пользовательскими данными и изменённая база правил.

## Проверка поставки

1. Проверить содержимое `data/rules.json`. Если требуется исходный учебный набор, использовать `data/demo_rules.json`.
2. Создать архив и проверить его состав. В нём должны присутствовать README, зависимости, исходники и примеры.
3. Распаковать архив в новую папку. Создать окружение и установить зависимости по [README](../README.md#3-установка-и-запуск).
4. Запустить тесты и приложение. Проверить загрузку примера и обмен JSON.
5. При наличии выполненного нейросетевого эксперимента приложить проверенные ответы, параметры и метрики отдельно. Автоматическая упаковка не включает все сырые ответы.

Окружение и модель устанавливаются на компьютере получателя отдельно. Проверка установки на независимом компьютере остаётся частью приёмки проекта.

`scripts/prepare_data.py` перезаписывает синтетические примеры и `data/rules.json`. Он не требуется для установки и запуска. Для восстановления базы через интерфейс можно импортировать `data/demo_rules.json`, предварительно сохранив текущую базу.
